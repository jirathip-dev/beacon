# beacon
Beacon: standalone iPhone uptime monitor + host heartbeat CLI

## CLI

Install: `cargo install --git https://github.com/jirathip-dev/beacon beacon`

The docs are in [docs/](docs/), one file per area: [run.md](docs/run.md) (checking a config, running the checks
once), [serve.md](docs/serve.md), [alerts.md](docs/alerts.md), [rules.md](docs/rules.md) (metric rules),
[jobs.md](docs/jobs.md) and [install.md](docs/install.md) (the service, the Mini and the boat VMs).
